船期查询 Voyage Schedule
按港口查询未来船期（预计停靠 / 预计离港 / 闸口 / 船代），命中后可一键写入对应代理船舶的靠泊与离泊时间。
船名与码头航次至少填一个；留空起始日期则按今天。该查询只返回「今天及之后离港」的航次，历史航次查不到。
船舶基本信息维护 Vessel Master
维护船舶主数据（船名 / IMO / MMSI / 国籍 / 船长 / 船宽 / 净吨）。新增代理船舶时可直接从此处选取，自动带出基本信息。
本港代理/服务商信息维护 Local Agent & Service Provider Master
维护本港代理与服务商公司档案（中英文公司名 / 联系人 / 邮箱电话 / 中英文地址 / 邮编 / 备注 / 收费价格表）。「类型」的维护方式与「交通凭证 → 港口列表」相同，可自行增删：类型为「本港代理」的公司只会出现在航次表单的「本港代理」单选栏，其它类型只会出现在「本港服务商」多选栏。点击列表任意一行可展开详情（收费价格表 / 备注全文）。
委托方信息维护 Client Master
维护委托方档案。一家公司可以有多个联系人——同一公司共用公司名称与地址，姓名 / 职位 / 电话 / 手机 / 邮箱 / 备注 / VIP 由每位联系人单独填写。点击公司行展开即可看到名下全部联系人，VIP 以 ★ 金色高亮。
交通凭证 Transportation Voucher
为船员 / 工作人员生成接送凭证。船名取自「当前代理船舶」与「船舶主数据」，港口取自全系统统一的港口列表——两处共用同一份数据，在船舶详情里改港口，凭证这里立刻同步。
⚓ 港口列表 Ports
这里的港口会被「船舶航次信息 → 港口」和凭证顶部的 PORT 下拉共用。
接驳地点属于当前选中的港口。
👥 乘客名单 Passengers
主名单，凭证可按行程单独勾选本次乘车的人。
