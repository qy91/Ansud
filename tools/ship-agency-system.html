船舶基本信息维护 Vessel Master
维护船舶主数据（船名 / IMO / MMSI / 国籍 / 船长 / 船宽 / 净吨）。新增代理船舶时可直接从此处选取，自动带出基本信息。
本港代理/服务商信息维护 Local Agent & Service Provider Master
维护本港代理与服务商公司档案（中英文公司名 / 联系人 / 邮箱电话 / 中英文地址 / 邮编 / 备注 / 收费价格表）。「类型」选代理的可在航次「本港代理」中选取，选服务商的可在航次「本港服务商」中多选。
委托方信息维护 Client Master
维护委托方档案（公司名称 / 姓名 / 职位 / 电话 / 手机 / 地址 / 邮箱 / 备注）。新增代理船舶时「委托方」可从此处选取。
交通凭证 Transportation Voucher
为船员 / 工作人员生成接送凭证。船名取自「当前代理船舶」与「船舶主数据」，港口取自全系统统一的港口列表——两处共用同一份数据，在船舶详情里改港口，凭证这里立刻同步。
⚓ 港口列表 Ports
这里的港口会被「船舶航次信息 → 港口」和凭证顶部的 PORT 下拉共用。
接驳地点属于当前选中的港口。
👥 乘客名单 Passengers
主名单，凭证可按行程单独勾选本次乘车的人。
